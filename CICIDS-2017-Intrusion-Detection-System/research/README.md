# Existing research implementation

This folder preserves the original CICIDS-2017 research scripts and saved evaluation summaries.

- `legacy_scripts/`: original Python scripts, retained for reference; paths and dependencies may need updating before execution.
- `results/`: previously saved model-comparison summaries. These are historical outputs and have not yet been independently reproduced.

Trained `.pkl` model files and raw CICIDS datasets are intentionally excluded from this Git repository. Do not connect a saved model to the app until its exact feature order and fitted preprocessing artifacts are recovered and validated.
